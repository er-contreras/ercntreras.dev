Step 2. Before we need to install one of the following oprions

Before we need to install in Debian

  
    sudo apt install libxcomposite-dev libxdamage-dev libxrandr-dev \
    libconfig-dev libdbus-1-dev libglx-dev libgl-dev \
    libdrm-dev libpcre3-dev libxft-dev libxinerama-dev

Dependencies when Fedora is used as distro

  
    sudo dnf install libXcomposite-devel libXdamage-devel \
    libXrandr-devel libconfig-devel dbus-devel libGL-devel \
    pcre-devel

Step 3. Install

sudo apt install xinit

OPTIONAL - To create sessions with different desktop environment

cd /usr/share/sessions
touch dwm.desktop

Add the next in case of using Debian GNOME or another desktop environment [!Important] If using with minimal Debian is not necessary to do this configuration. 

  
    [Desktop Entry]
    Encoding=UTF-8
    Name=Dwm
    Comment=Dynamic windowmanager
    Exec=dwm
    Icon=dwm
    Type=XSession

Step 4. The directories as dwm, st and dmenu doesn't have any change until here, you just have to compile and run 

make
sudo make clean install

Add autostart.sh

You have to change autostart.sh permissions to exec

chmod +x autostart.sh

ADD THIS LINE IN .XINITRC TO RUN YOUR SCRIPT

$HOME/.dwm/autostart.sh &

There are some executable that require to be added to ~/.dwm/autostart.sh to make them work if you are not including them in the .xinitrc file. 

  
    #!/bin/bash
    xrandr --output eDP-1 --off &
    exec slstatus &
    nitrogen --restore &
    exec compton &

Step 5. The executables like slstatus and compton needs to be symlink so you have to do the next:

sudo ln -sf ~/.config/suckless/slstatus/slstatus /usr/local/bin
sudo ln -sf ~/.config/suckless/compton/compton /usr/local/bin

Patching Example:

mkdir patches
cd patches

Select one of the patches from DWM, DMW or ST
curl -O <githuburl-of-diff>
cd ../
patch -p1 <patches <diff-file>
rm -rf config.h
make
sudo make clean install
